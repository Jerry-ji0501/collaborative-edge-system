# Mindstream · 意识流

一部 30 秒、全程序化生成的手作质感动画短片。Vite + TypeScript + Canvas 2D，无任何图片素材、无第三方运行时依赖。

```
小生物 → 神经电脉冲 → 三棱镜色散 → 彩虹同心环 → 向日葵 → 螺旋星系 → 黑洞 → 时空隧道 → 地出 → 回到小生物
```

## 运行

```bash
npm install
npm run dev        # 本地预览（自动播放、循环）
npm run build      # 输出 dist/，并额外生成单文件 dist/mindstream.html
```

播放控制（刻意保持极简，不显示任何 UI）：

| 按键 | 作用 |
| --- | --- |
| 空格 / 点击画面 | 暂停 / 继续 |
| ← / → | 逐帧（按住 Shift 为 ±1 秒） |
| R | 从头播放 |
| F | 全屏 |
| `?t=12.5` | 从指定秒数开始 |

移动鼠标时底部会短暂出现一条进度细线。

## 画布与时间

- 设计坐标系固定为 **1920 × 1080**，所有场景都在这个坐标系里绘制；`main.ts` 按窗口等比缩放到 16:9，并按 `devicePixelRatio`（上限 2，宽度上限 3840）设置真实像素，高分屏上锐利。
- **确定性时间轴**：墙钟时间被量化为整数帧（30 fps），每一帧都是 `renderFilm(ctx, t)` 的纯函数——没有累积的物理状态，所有随机都来自固定种子。任意时间点可随机访问，逐帧导出结果与实时播放完全一致。
- `window.__film.renderAt(t)` 供无头浏览器逐帧导出视频。

## 结构

```
src/
  main.ts              画布、DPR、30fps 时钟、按键
  film.ts              导演：背景色流、场景层顺序、纸张/颗粒叠加
  core/
    timeline.ts        关键时间点、明暗(darkness)曲线
    camera.ts          连续镜头函数（棱镜→星系→黑洞是同一条镜头曲线）
    geometry.ts        场景之间的共享锚点（入射点、环心、地面线）
    draw.ts            手绘图元：平滑路径、变宽墨线、抖动圆、光晕贴图、批量描边
    texture.ts         程序化纸纹 + 胶片颗粒（启动时生成一次）
    noise.ts rng.ts    带种子的值噪声 / 随机数
    math.ts color.ts   缓动、阻尼弹簧、调色板
  scenes/
    character.ts       小生物：步态、挤压拉伸、次级动作（天线）、表情
    neurons.ts         分形树突生长、脉冲、火花、被拉直成光束的那一枝
    prism.ts           光束、玻璃棱镜、色散 → 等曲率弯曲 → 同心环
    sunflower.ts       环→花瓣/萼片/花盘，黄金角种子，花瓣剥离成星
    galaxy.ts          4680 个粒子：种子→旋臂→吸积盘，引力透镜近似，落入视界
    starfield.ts       视差星空、透镜偏折、径向拉伸
    tunnel.ts          手绘环形隧道（虚线、珠串、点环），尽头凝聚成光柱
    earthrise.ts       光柱放平成地平线、月面、球面投影的矢量地球
    finale.ts          地球辉光凝成小光球，落回小生物身旁
```

## 转场是怎么"连"起来的

| 时间 | 转场 | 做法 |
| --- | --- | --- |
| 2.9–5.5s | 光点 → 神经网络 | 光点就是网络的根；生长前沿按"到根距离"推进，角色层反向缩小形成体量对比 |
| 6.5–7.8s | 神经 → 光束 | 选中最左侧的一枝，按弧长逐点插值到一条水平线（根部先绷直，像鞭子收紧）；其余网络随暮色（经由薰衣草色）退入深蓝 |
| 9.5–11.0s | 色散 → 同心环 | 每条色带始终是"等曲率圆弧"，只插值起点、方向、曲率与长度，于是直线光带连续弯成共心的环 |
| 11.0–12.5s | 环 → 向日葵 | 红/橙环切成扇形并长成花瓣（尖端先收、根部后收），绿环成萼片，青环成花盘边，蓝紫环碎成 520 颗黄金角种子；米色从花心径向铺开 |
| 13.8–15.5s | 向日葵 → 星系 | 花心加速旋转；每颗种子分裂为 9 个粒子，在极坐标下插值到对数螺线旋臂（天然形成螺旋轨迹）；花瓣剥离缩成星点；背景走一遍"黄→橙→玫瑰→紫→深蓝"的日落 |
| 17.0–18.4s | 星系 → 黑洞 | 同一批粒子半径收缩到吸积盘、角速度按开普勒式加速、沿切向拉出拖尾；视界从中心长出 |
| 20.1–21.0s | 黑洞 → 隧道 | 盘面转正成同心环，镜头指数级推进，隧道通过视界"开口"被看见 |
| 22.5–24.0s | 隧道 → 地平线 | 环向中心坍缩成光柱，光柱放平、下沉并贴合月面地平线 |
| 26.9–28.9s | 地球 → 小生物 | 推向海面反光点，蓝色光球收缩；背景把日落倒放一遍回到米色；光点飘落，镜头拉远 |

## 视觉约定

- 线条"沸腾"：所有手绘轮廓的抖动噪声以 12 fps 刷新（`boilOf`），像手绘动画的一拍二。
- 纸纹以 `soft-light` 叠加、颗粒以 `overlay` 叠加，亮场与暗场都能透出质感。
- 光晕在纸面上用"涂色"（source-over），在夜空里用"发光"（lighter），由 `darkness(t)` 平滑切换。
