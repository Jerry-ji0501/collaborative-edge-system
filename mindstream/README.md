# Mindstream · 意识流

一部 30 秒、全程序化生成的手作质感动画短片。Vite + TypeScript + Canvas 2D，无任何图片素材、无第三方运行时依赖。声音同样由代码生成：用浏览器自带的 Web Audio 实时合成，无任何音频文件，并与画面逐帧对齐。

```
小生物 → 神经电脉冲 → 三棱镜色散 → 彩虹同心环 → 向日葵 → 螺旋星系 → 黑洞 → 时空隧道 → 地出 → 回到小生物
```

## 运行

```bash
npm install
npm run dev        # 本地预览（自动播放、循环）
npm run build      # 输出 dist/，并额外生成单文件 dist/mindstream.html
```

播放控制（刻意保持极简，不显示任何 UI）：

| 按键 | 作用 |
| --- | --- |
| 空格 / 点击画面 | 暂停 / 继续 |
| ← / → | 逐帧（按住 Shift 为 ±1 秒） |
| R | 从头播放 |
| F | 全屏 |
| M | 声音 开 / 关 |
| `?t=12.5` | 从指定秒数开始 |
| `?mute` | 静音启动（按 M 开启声音） |

移动鼠标时底部会短暂出现一条进度细线，右下角同时出现一个小喇叭（点击开关声音）。

浏览器只允许在用户手势之后发声，所以影片自动播放时是无声的：**第一次点击或按键即开启声音**——第一次点击画面只开声音、不会暂停。

## 画布与时间

- 设计坐标系固定为 **1920 × 1080**，所有场景都在这个坐标系里绘制；`main.ts` 按窗口等比缩放到 16:9，并按 `devicePixelRatio`（上限 2，宽度上限 3840）设置真实像素，高分屏上锐利。
- **确定性时间轴**：墙钟时间被量化为整数帧（30 fps），每一帧都是 `renderFilm(ctx, t)` 的纯函数——没有累积的物理状态，所有随机都来自固定种子。任意时间点可随机访问，逐帧导出结果与实时播放完全一致。
- `window.__film.renderAt(t)` 供无头浏览器逐帧导出视频；`window.__film.renderAudio()` 用 `OfflineAudioContext` 把整条声轨离线渲染出来（base64 编码的 16-bit 立体声 WAV，从第 0 帧对齐），与逐帧导出的画面直接合成即可，和实时播放听到的是同一份乐谱。

## 结构

```
src/
  main.ts              画布、DPR、30fps 时钟、按键
  film.ts              导演：背景色流、场景层顺序、纸张/颗粒叠加
  core/
    timeline.ts        关键时间点、明暗(darkness)曲线
    camera.ts          连续镜头函数（棱镜→星系→黑洞是同一条镜头曲线）
    geometry.ts        场景之间的共享锚点（入射点、环心、地面线）
    draw.ts            手绘图元：平滑路径、变宽墨线、抖动圆、光晕贴图、批量描边
    texture.ts         程序化纸纹 + 胶片颗粒（启动时生成一次）
    noise.ts rng.ts    带种子的值噪声 / 随机数
    math.ts color.ts   缓动、阻尼弹簧、调色板
  scenes/
    character.ts       小生物：步态、挤压拉伸、次级动作（天线）、表情
    neurons.ts         分形树突生长、脉冲、火花、被拉直成光束的那一枝
    prism.ts           光束、玻璃棱镜、色散 → 等曲率弯曲 → 同心环
    sunflower.ts       环→花瓣/萼片/花盘，黄金角种子，花瓣剥离成星
    galaxy.ts          4680 个粒子：种子→旋臂→吸积盘，引力透镜近似，落入视界
    starfield.ts       视差星空、透镜偏折、径向拉伸
    tunnel.ts          手绘环形隧道（虚线、珠串、点环），尽头凝聚成光柱
    earthrise.ts       光柱放平成地平线、月面、球面投影的矢量地球
    finale.ts          地球辉光凝成小光球，落回小生物身旁
  audio/
    engine.ts          音频引擎：影片时钟 → 音频时钟、预排程、逐帧参数、暂停/跳转/循环、离线渲染
    score.ts           乐谱：什么声音在哪一帧响起（读取与画面相同的时间键和种子数据）
    synth.ts           乐器：程序化噪声/噼啪/混响尾巴，以及脚步、铃、弹簧、火花、玻璃、风……
```

## 转场是怎么"连"起来的

| 时间 | 转场 | 做法 |
| --- | --- | --- |
| 2.9–5.5s | 光点 → 神经网络 | 光点就是网络的根；生长前沿按"到根距离"推进，角色层反向缩小形成体量对比 |
| 6.5–7.8s | 神经 → 光束 | 选中最左侧的一枝，按弧长逐点插值到一条水平线（根部先绷直，像鞭子收紧）；其余网络随暮色（经由薰衣草色）退入深蓝 |
| 9.5–11.0s | 色散 → 同心环 | 每条色带始终是"等曲率圆弧"，只插值起点、方向、曲率与长度，于是直线光带连续弯成共心的环 |
| 11.0–12.5s | 环 → 向日葵 | 红/橙环切成扇形并长成花瓣（尖端先收、根部后收），绿环成萼片，青环成花盘边，蓝紫环碎成 520 颗黄金角种子；米色从花心径向铺开 |
| 13.8–15.5s | 向日葵 → 星系 | 花心加速旋转；每颗种子分裂为 9 个粒子，在极坐标下插值到对数螺线旋臂（天然形成螺旋轨迹）；花瓣剥离缩成星点；背景走一遍"黄→橙→玫瑰→紫→深蓝"的日落 |
| 17.0–18.4s | 星系 → 黑洞 | 同一批粒子半径收缩到吸积盘、角速度按开普勒式加速、沿切向拉出拖尾；视界从中心长出 |
| 20.1–21.0s | 黑洞 → 隧道 | 盘面转正成同心环，镜头指数级推进，隧道通过视界"开口"被看见 |
| 22.5–24.0s | 隧道 → 地平线 | 环向中心坍缩成光柱，光柱放平、下沉并贴合月面地平线 |
| 26.9–28.9s | 地球 → 小生物 | 推向海面反光点，蓝色光球收缩；背景把日落倒放一遍回到米色；光点飘落，镜头拉远 |

## 视觉约定

- 线条"沸腾"：所有手绘轮廓的抖动噪声以 12 fps 刷新（`boilOf`），像手绘动画的一拍二。
- 纸纹以 `soft-light` 叠加、颗粒以 `overlay` 叠加，亮场与暗场都能透出质感。
- 光晕在纸面上用"涂色"（source-over），在夜空里用"发光"（lighter），由 `darkness(t)` 平滑切换。

## 声音

一切都在浏览器里用 Web Audio 实时合成：振荡器、滤波器、包络，加上启动时由固定种子生成的白/粉/棕噪声、电火花噼啪声和两段合成混响（纸面上的小房间、太空里的长厅）。没有任何音频文件。

**与画面对齐。** 声音和画面一样是影片时间的纯函数，分两类：

- **单次事件**（脚步、铃、弹跳、火花、撞击、落地……）在音频时钟上提前 0.25 秒排好。看得见的节拍被量化到它们**第一次出现在画面上的那一帧**；密集的火花与风的阵涌保留精确时刻（按帧量化会在 30 Hz 上发出嗡嗡声）。
- **连续声层**（电流底噪、共鸣、音垫、轰鸣、风、长音）是由 `f(t)` 驱动的 `AudioParam`，**每一帧设一个点**，帧间线性过渡。

影片时钟是 `performance.now()` 量化成的帧；引擎用 `AudioContext.getOutputTimestamp()` 算出"此刻从扬声器出来的是哪一个音频采样"，再加上约 25 ms 的显示延迟（rAF → 下一次垂直同步 → 扫描），于是每个声音恰好在它那一帧亮起时被听到。暂停、逐帧、跳转、循环都只是从新的播放头重新读一遍乐谱，没有累积状态；暂停、静音或标签页隐藏时音频设备会休眠。

**事件从哪来。** 乐谱不另记时间，而是读画面自己的数据：脚步来自步态相位（每 96 px 落一只脚），火花、节点闪亮和卫星细胞来自神经网络同一份带种子的生长数据（并按屏幕位置定声像），风的阵涌来自每一道环擦过画面边缘的时刻，光点的落地与回弹来自它的阻尼弹跳曲线。

| 帧时刻 | 画面 | 声音 |
| --- | --- | --- |
| 0.13–2.90s | 小生物走进画面（10 步 + 停步） | 毛毡落在纸上的脚步：随刹车越走越轻，左右脚音高略不同，声像随身体从左侧移到中央（前两步在画外） |
| 3.13s | 看见光点，眼睛睁大 | "叮"——A5 小铃，从光点的方向传来 |
| 3.27–3.63s | 下蹲蓄力 → 起跳 → 落地 | 弹簧"嘣～"：下蹲时压低，起跳时音高与共振峰一起弹起并颤动；落地时两只脚先后着地 |
| 3.63s | 光点炸开成神经网络 | 一声电流"嗞"，伴着噼啪 |
| 3.6–7.5s | 生长、脉冲、火花、节点闪亮、卫星细胞点亮 | 细碎的电流声：每一簇火花一粒噼啪，每个节点闪亮一声"嘶"（节点越小越高），声像跟随屏幕位置；底噪随生长速度和在途信号数量起伏；6 个卫星细胞依次点亮，是一串上行的 D 五声音阶 |
| 6.45–7.78s | 选中的一枝发光、被拉直 | 一道纤细的五度从 A4 升到 A5——D 大调的属音 |
| 7.55–8.05s | 白光从左射向棱镜 | 由左向右、越来越亮的"嗖" |
| 8.07s | 白光撞上棱镜 | 一声清亮的共鸣：玻璃的敲击，然后七个分音（每条色带一个，红色最低）随光谱展开绽放成 D 大调和弦，按敲击时刻闪烁，并随同心环一起"呼吸" |
| 11.05–20.8s | 环 → 向日葵 → 星系 → 黑洞 | 环境音垫：随米色从花心铺开而展开，与向日葵同频呼吸；和弦 I（温暖）→ vi（日落）→ IV（星系）→ i（坍缩）→ 空五度（黑洞），各声部像花瓣那样依次滑动，滤波逐渐合上、音区逐渐下沉 |
| 17.2–21.1s | 视界张开、镜头推进、坠入 | 低频轰鸣：D1 次低音 + 棕噪声 + 缓慢起伏的低吼，随视界半径出现，随推镜增强，坠入时被拖高 |
| 20.15–22.85s | 坠入视界、穿越隧道 | 风声：柔和的风体加三道游移的哨音，随前进速度变化；每道环擦过画面边缘时一阵风（约每秒 10 次）；环坍缩成光时，风被吸进光里 |
| 22.74–28.0s | 光柱 → 地平线 → 地出 → 海面反光 | 全片最安静的长音：A3，带极弱的八度与十二度，随光柱出现、随地球升起微微抬起；海面反光时一丝高音随闪光明灭 |
| 28.57s · 28.87s · 29.17s | 光点落地，轻弹两下 | 轻轻一声 D5，两次回弹更轻 |
| 29.10–29.53s | 小生物看见光点、天线亮起、再跳一次 | 开场那声铃回来了，这次落在 D6（从 A 解决到 D）；更轻的弹跳与落地 |
